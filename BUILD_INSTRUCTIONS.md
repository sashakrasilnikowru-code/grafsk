# Инструкция по сборке приложений (.exe и .apk)

Этот проект подготовлен для локальной сборки десктопного приложения для Windows (`.exe`) с помощью **Electron** и мобильного приложения для Android (`.apk`) с помощью **Capacitor**.

Поскольку для сборки требуются системные зависимости (Node.js, Android Studio), это нужно сделать на вашем компьютере. Следуйте простым шагам ниже.

## 🛠 Предварительная подготовка

Перед началом убедитесь, что у вас установлен **Node.js** (версия 18 или выше).
Если его нет, скачайте и установите с официального сайта: [https://nodejs.org/](https://nodejs.org/)

1. Скачайте этот репозиторий на свой компьютер и распакуйте его (или сделайте `git clone`).
2. Откройте терминал (командную строку / PowerShell) в папке с проектом.
3. Установите необходимые зависимости, выполнив команду:

```bash
npm install
```

---

## 🖥 Как собрать `.exe` (для Windows)

1. Откройте терминал в папке проекта.
2. Выполните команду:

```bash
npm run build:exe
```

3. Дождитесь окончания процесса. После этого в папке проекта появится новая папка `build-exe`.
Внутри нее вы найдете готовый установочный файл (например, `График смен Setup 1.0.0.exe`).

*(Вы можете проверить, как выглядит приложение на ПК без сборки, просто запустив команду `npm start`)*

---

## 📱 Как собрать `.apk` (для Android)

Для компиляции Android-приложения вам понадобится установленный **Android Studio**. Скачать его можно здесь: [https://developer.android.com/studio](https://developer.android.com/studio).

### Шаг 1: Инициализация Android проекта
В терминале в папке с вашим проектом выполните по очереди две команды:

```bash
npm run build:web
npm run init:android
```
*(Эта команда скопирует ваш `index.html` и создаст папку `android` с системными файлами мобильного приложения).*

### Шаг 2: Синхронизация кода
Каждый раз, когда вы вносите изменения в `index.html`, вам нужно обновлять код в Android-проекте:

```bash
npm run build:apk
```

### Шаг 3: Создание `.apk` файла
1. Откройте **Android Studio**.
2. Нажмите **Open** и выберите папку `android`, которая появилась внутри вашего проекта.
3. Дождитесь, пока Android Studio загрузит проект (внизу будет идти процесс загрузки Gradle, это может занять пару минут).
4. В верхнем меню выберите: **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
5. Когда сборка завершится, в правом нижнем углу появится всплывающее окно. Нажмите **"locate"** (найти), чтобы открыть папку, в которой лежит ваш готовый файл `app-debug.apk`. Вы можете переименовать его и установить на телефон!
